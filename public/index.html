Conexión a PostgreSQL

La conexión se configura solo en el servidor mediante el archivo local .env.

  1. Edita .env con los datos del servidor, base de datos y usuario.
  2. Guarda el archivo y reinicia la aplicación con npm start.
  3. Usa el botón para comprobar la conexión y las tablas requeridas.

La contraseña no se muestra ni se envía al navegador. No compartas ni subas el archivo .env.
